# Presentation Maker

Веб-приложение для создания и редактирования презентаций.

Проект позволяет создавать презентации из слайдов, добавлять текстовые и графические объекты, изменять фон слайдов и просматривать готовую презентацию в режиме предпросмотра.

## Возможности

* создание презентации;
* изменение названия презентации;
* добавление, удаление и перемещение слайдов;
* дублирование слайдов;
* добавление текстовых объектов;
* добавление изображений;
* перемещение и изменение размера объектов;
* изменение стиля текста;
* изменение фона слайда:

  * цвет;
  * изображение;
  * градиент;
* сохранение презентации в JSON;
* загрузка презентации из JSON;
* режим предпросмотра презентации;
* навигация между слайдами в режиме предпросмотра.

## Структура проекта

```text
src/
├── components/        # React-компоненты интерфейса
├── functions/         # Функции изменения модели презентации
├── types/             # Типы данных приложения
├── __test__/           # Тесты
├── editor.ts          # Состояние редактора и связь UI с моделью
├── data.ts             # Начальные/тестовые данные
└── index.tsx           # Точка входа приложения
```

### Архитектура

Проект разделён на несколько уровней:

```text
React Components
       ↓
    editor.ts
       ↓
Presentation modifiers
       ↓
Slide/Object modifiers
       ↓
Presentation model
```

React-компоненты отвечают за отображение интерфейса и обработку действий пользователя.

`editor.ts` хранит текущее состояние редактора и является связующим слоем между интерфейсом и функциями изменения модели.

Функции из `functions/` изменяют модель презентации и возвращают её новую версию без изменения исходных объектов.

Типы данных приложения находятся в `types/`.

## Установка

Клонировать репозиторий:

```bash
git clone <repository-url>
cd presentation-maker
```

Установить зависимости:

```bash
npm install
```

## Запуск

Запустить приложение в режиме разработки:

```bash
npm run dev
```

После запуска открыть адрес, указанный Vite в терминале.

## Тестирование

Запустить все тесты:

```bash
npm test
```

Запустить тесты один раз:

```bash
npx vitest run
```

Запустить тесты конкретного файла:

```bash
npx vitest run src/__test__/objects.test.ts
```

## Сборка

Создать production-сборку:

```bash
npm run build
```

Предварительно проверить production-сборку:

```bash
npm run preview
```

## Основные сущности

### Presentation

Презентация содержит название и список слайдов.

### Slide

Слайд содержит:

* идентификатор;
* название;
* описание;
* фон;
* список объектов.

### SlideObject

Объект слайда может быть:

* текстовым;
* медиа-объектом.

Текстовый объект содержит текст и настройки форматирования.

Медиа-объект содержит источник и тип медиа.

## Тесты

Для проверки функций модели используется Vitest.

Тестируются операции с:

* презентациями;
* слайдами;
* объектами слайдов;
* фоном слайдов.

Особое внимание уделяется тому, что функции-модификаторы не изменяют исходную модель, а возвращают её новую версию.
